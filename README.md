# Crimson Tasks

Одностраничный список задач на FastAPI, SQLite и Vanilla JavaScript. Задачи можно добавлять, переименовывать, отмечать выполненными и удалять. Чекбокс меняет статус в обе стороны, карандаш открывает редактирование, а корзина запрашивает подтверждение. Фильтры и счётчики обновляются без перезагрузки. Данные сохраняются после закрытия страницы и перезапуска сервера.

«Добавить» или Enter открывает окно создания с названием, календарём дедлайна и ползунком важности. Календарь начинается с понедельника, позволяет переключать месяцы и выбирать часы и минуты с клавиатуры. Предпросмотр показывает местные дату и время. Доступны быстрые варианты «Через час», «Завтра» и «Через неделю». Последние два сохраняют местное время текущего момента и сдвигают календарную дату. Прошедшие дни недоступны, время проверяется перед отправкой.

Без выбранной даты задача создаётся без срока. В окне редактирования можно менять название, срок и важность. Кнопка «Без срока» снимает дедлайн после сохранения. Просроченный сохранённый дедлайн разрешено оставить при правке других полей. Изменённый срок должен быть в будущем.

Важность задаётся пользователем от 0 до 100, значение по умолчанию — 50. Ползунок меняет значение с шагом 5 и поддерживает клавиатуру. Уровни важности — низкая до 25, средняя от 25, высокая от 50 и критическая от 80. Срочность рассчитывается отдельно по времени и обновляется раз в минуту и при возвращении на вкладку.

Интерфейс адаптируется к мобильному экрану и работает с клавиатуры. Исходный макет и результаты приёмки доступны в репозитории. [Визуальный макет](docs/design/crimson-tasks.png) · [План разработки](PLAN.md)

## Установка и запуск

Нужны Python 3.12 или новее и `uv`. Выполните из корня проекта.

```sh
uv sync --locked
uv run --locked uvicorn app.main:app --reload
```

Откройте [Crimson Tasks](http://127.0.0.1:8000). Список при первом запуске пуст. Приложение создаёт `data/tasks.sqlite3` при старте. Чтобы использовать другую базу, задайте переменную окружения `CRIMSON_DB_PATH` с абсолютным путём к файлу.

## Проверка

```sh
uv run --locked pytest
node --test tests/task-timing.test.cjs
```

Интеграционные тесты используют временные SQLite-файлы. Они проверяют HTTP-операции, валидацию, миграцию старой схемы, UTC, важность, время завершения и сохранение данных после повторного запуска. Node.js нужен для тестов frontend-расчётов и использует встроенный тестовый раннер. Для проверки интерфейса создайте задачу через Enter, переключите её статус в обе стороны, проверьте счётчики во всех фильтрах, обновите страницу и удалите задачу.

## API

| Метод и путь | Действие |
| --- | --- |
| `GET /api/tasks` | Получить все задачи. |
| `POST /api/tasks` | Создать активную задачу. Обязателен `title`, доступны `due_at` и `importance`. |
| `PATCH /api/tasks/{task_id}` | Изменить `title`, `due_at`, `importance` или булево `is_completed`. Пропущенные поля сохраняют своё значение. `due_at: null` снимает дедлайн. |
| `DELETE /api/tasks/{task_id}` | Удалить задачу. Успешный ответ имеет статус `204`. |

Название содержит от 1 до 200 символов после удаления пробелов по краям. Интерактивное описание доступно в [Swagger UI](http://127.0.0.1:8000/docs).

Даты API содержат часовой пояс, сохраняются в UTC и возвращаются с `Z`. Дедлайн без часового пояса отклоняется. `created_at` устанавливает сервер, `completed_at` фиксируется только при переходе в выполненное состояние и сбрасывается при возврате в активное. В браузере даты показаны в локальном часовом поясе.

При старте схема SQLite автоматически расширяется в транзакции с блокировкой записи. Существующие задачи сохраняют идентификаторы, названия и статусы. Их неизвестное время создания заполняется единым временем миграции. Дедлайн и неизвестное время завершения остаются пустыми, важность получает 50. Перед обновлением сервера сохраните резервную копию файла БД. Старые версии приложения следует остановить перед запуском обновлённой.

Прогресс показывает долю израсходованного времени от создания до дедлайна. Статусы проверяются по приоритету — выполнено, просрочено, осталось не более трёх часов, прошло не менее 80%, не менее 50%, времени достаточно. Значение полосы ограничено 0–100%. У выполненных задач оно фиксируется на момент завершения. Для старых выполненных задач с неизвестным временем завершения полоса скрыта. Расчёт в интерфейсе использует часы устройства.

## Публикация демо

На сервере или хостинге с поддержкой Python выделите постоянный диск и задайте `CRIMSON_DB_PATH` внутри него. Настройте HTTPS и автоматический перезапуск процесса. Для демо достаточно одного экземпляра приложения.

```sh
uv sync --locked --no-dev
uv run --locked --no-dev uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Укажите порт, который выделяет хостинг. После развёртывания создайте пробную задачу и проверьте её наличие после перезапуска. Приложение использует общий список без учётных записей, поэтому публичное демо должно работать с отдельной базой демонстрационных данных.
