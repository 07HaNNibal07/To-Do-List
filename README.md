# Crimson Tasks

Одностраничный список задач на FastAPI, SQLite и Vanilla JavaScript. Задачи можно добавлять, отмечать выполненными, возвращать в активные и удалять. Три фильтра и счётчики обновляются без перезагрузки. Данные сохраняются после закрытия страницы и перезапуска сервера.

Интерфейс адаптируется к мобильному экрану и работает с клавиатуры. Исходный макет и результаты приёмки доступны в репозитории. [Визуальный макет](docs/design/crimson-tasks.png) · [План разработки](PLAN.md)

## Установка и запуск

Нужны Python 3.12 или новее и `uv`. Выполните из корня проекта.

```sh
uv sync --locked
uv run --locked uvicorn app.main:app --reload
```

Откройте [Crimson Tasks](http://127.0.0.1:8000). Список при первом запуске пуст. Приложение создаёт `data/tasks.sqlite3` при старте. Чтобы использовать другую базу, задайте переменную окружения `CRIMSON_DB_PATH` с абсолютным путём к файлу.

## Проверка

```sh
uv run --locked pytest
```

Интеграционные тесты используют временные SQLite-файлы. Они проверяют HTTP-операции, валидацию, повторную установку статуса и сохранение данных после повторного запуска. Для проверки интерфейса создайте задачу через Enter, переключите её статус в обе стороны, проверьте счётчики во всех фильтрах, обновите страницу и удалите задачу.

## API

| Метод и путь | Действие |
| --- | --- |
| `GET /api/tasks` | Получить все задачи. |
| `POST /api/tasks` | Создать активную задачу. Тело запроса содержит `title`. |
| `PATCH /api/tasks/{task_id}` | Установить статус. Тело запроса содержит булево `is_completed`. |
| `DELETE /api/tasks/{task_id}` | Удалить задачу. Успешный ответ имеет статус `204`. |

Название содержит от 1 до 200 символов после удаления пробелов по краям. Интерактивное описание доступно в [Swagger UI](http://127.0.0.1:8000/docs).

## Публикация демо

На сервере или хостинге с поддержкой Python выделите постоянный диск и задайте `CRIMSON_DB_PATH` внутри него. Настройте HTTPS и автоматический перезапуск процесса. Для демо достаточно одного экземпляра приложения.

```sh
uv sync --locked --no-dev
uv run --locked --no-dev uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Укажите порт, который выделяет хостинг. После развёртывания создайте пробную задачу и проверьте её наличие после перезапуска. Приложение использует общий список без учётных записей, поэтому публичное демо должно работать с отдельной базой демонстрационных данных.
